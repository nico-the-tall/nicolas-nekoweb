# Nico's Space

This repository contains all the code and static assets for my personal website: https://nicolas.nekoweb.org

If you want to run the website locally on your machine:

- Install Node.js v24 from https://nodejs.org/
- Install pnpm v11.5.1 from https://pnpm.io/

Once available on your machine, run on your terminal:

```sh
# Make sure you clone the repository first and point your terminal at the correct dir.
pnpm install
pnpm dev
```

The page will be locally available on https://localhost:5173 (by default)
